Engineering Philosophy

🏛️

Architecture before code.

Every system begins with a clear threat model — failure modes, data consistency boundaries, and operational bottlenecks mapped before writing code. Complexity is managed through constraint.

⚡

Operational readiness is a feature.

Software that works on localhost and software that survives production are two different products. Deployment pipelines, environment configs, and failure recovery are built into the spec.

📦

The system is the product.

Individual components are not deliverables. A working, monitored, documented system that a non-technical operator can maintain without calling the developer — that is the deliverable.

Engineering Case Studies

CS-01 Cloud Infrastructure Video Processing Mobile
Achieved sub-2-second live feed latency with a resilient offline queue guaranteeing zero archive frame loss across unstable network conditions.

VSaaS — Video Surveillance as a Service

The Constraint

RTSP camera networks installed in retail environments operate over consumer-grade Wi-Fi — connections that drop, degrade, and recover unpredictably throughout the day. A naive streaming pipeline drops footage whenever connectivity lapses. The client requirement was unambiguous: zero frame loss in the historical archive, with live feeds that immediately snap back to real-time on reconnection.

Engineering Architecture

A Python bridge process ingests raw RTSP feeds and operates two simultaneous FFmpeg encoding pipelines: a rolling 2-second HLS playlist for live consumption, and 60-second .ts segment files for archival chunking. An intelligent thread-safe queue intercepts the upload path. During network outages, segments cache locally and are flushed to MinIO object storage in strict temporal order once connectivity resumes.

Live feeds intentionally discard stale frames during outages rather than serve delayed footage. The mobile application (React Native & Expo) stitches daily chunk sequences into continuous playback timelines queried from Supabase PostgreSQL metadata.

Stack
Python FFmpeg HLS/RTSP MinIO S3 Supabase React Native Expo Docker

CS-02 Enterprise SaaS POS System Redesigned UI
Replaced fragmented paper-based and spreadsheet workflows with a unified POS + repair management system, consolidating four operational roles under role-based access control.

RSManager — Repair Shop & Point of Sale Platform

The Constraint

Electronics repair shops operate across at least four distinct operational surfaces simultaneously: customer checkout (POS), device repair tracking, inventory management, and supplier procurement. Each surface had its own informal system, producing reconciliation errors and inventory blindspots.

Engineering Architecture

The backend is a FastAPI service with asynchronous SQLAlchemy ORM on PostgreSQL, secured with JWT authentication. Four role tiers — Owner, Manager, Technician, Cashier — enforce API-level permission boundaries. The POS module supports barcode scanning, trade-in discounts, custom line items, and thermal receipt output via python-escpos.

The frontend is a React + Vite application using TypeScript, TailwindCSS, and Zustand for global state. Bundled into a portable offline distribution for shops without reliable internet.

Stack
FastAPI Python PostgreSQL SQLAlchemy React TypeScript TailwindCSS Zustand

CS-03 Hyperlocal Delivery Flutter Mobile Real-Time GPS
Engineered a high-performance hyperlocal delivery ecosystem connecting customers, local merchants, and couriers with real-time order dispatching and live GPS tracking.

Jibli — Hyperlocal Delivery & Logistics Platform

The Constraint

Hyperlocal delivery in secondary Algerian cities faces unique challenges: unmapped neighborhoods, intermittent mobile data connectivity, and rapid order dispatching during peak hours. The system required zero-latency driver routing and instant order status synchronization.

CS-05 Data Engineering Automation Lead Generation
Automated extraction of Google Maps leads for dz_schools platform, bypassing dynamic anti-bot measures to build a comprehensive database of Algerian private schools.

DZ Lead Gen Pro — Automated Maps Scraper

The Constraint

The client needed a comprehensive database of private schools across all 58 Algerian wilayas. Manual data entry was unfeasible, and standard scraping scripts were immediately blocked by Google Maps' dynamic loading algorithms and anti-bot measures.

Engineering Architecture

An asynchronous Python application leverages the Playwright library to launch a headed Chromium browser with automation flags disabled. The scraper navigates region-by-region handling consent screens and dynamic scroll events. A Streamlit frontend provides a clean UI to configure parameters.

CS-06 Healthcare Ops Algorithm Design Institutional Tool
Eliminated scheduling bias and holiday-assignment disputes across medical on-call rosters by implementing a stateful fairness-guaranteed round-robin algorithm with historical memory.

DocsGuards — Medical On-Call Scheduling Engine

The Constraint

Hospital on-call scheduling is contentious territory: doctors track who was last assigned a major holiday, who has been on leave, and whether standard-night vs weekend pools are treated fairly. Manual spreadsheet scheduling introduces implicit bias.

Engineering Architecture

A custom continuous round-robin queuing engine maintains separate state machines for Standard and Weekend pools. The algorithm enforces a hard rule: no doctor receives a second assignment until every eligible non-leave doctor has received one. A Holiday Memory Engine stores per-holiday history.

Stack
Python 3.8+ Flask Round-Robin Engine openpyxl SQLite
